## HTML Forms Validation Practice

[Live Demo](https://karinamilko.github.io/HTML-Forms-Validation-Practice/)

## Overview
Adaptive contact form with input validation and responsive design.

## Features
- Flexbox layout for aligned inputs  
- Phone fields in one row  
- Validation via HTML attributes and `:valid` / `:invalid`
- Extra spaces in message removed 
- Submit handler collects all data into an object:

```js
{
  name, surname, email, phone, subject, message
}

## CSS Practice (Layout & Styling)
- Responsive layout using Flexbox
- Consistent input widths
- Visual validation feedback using `:valid` and `:invalid`
- Background image and basic UI styling
